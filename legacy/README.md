# Historical reference

This directory retains the original CSA Python source and figures for comparison with the
modern implementation in [`src/csa_inpainting`](../src/csa_inpainting/).
It is excluded from package installation, test discovery and linting.

The original source is based on
[`f0b0712aa950cc559062dfef04c2f3f884a1f3e2`](https://github.com/KumapowerLIU/CSA-inpainting/tree/f0b0712aa950cc559062dfef04c2f3f884a1f3e2).
Historical notebooks and compiled Python caches have been removed from this checkout.
Use the modern [command-line guide](../docs/USAGE.md) for all current workflows.

The Python files retain historical APIs and known issues; see the
[migration audit](../docs/MIGRATION.md) for their replacements.
